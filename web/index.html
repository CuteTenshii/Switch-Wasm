Drop a homebrew .nro or a title .nsp / .xci to boot

…or open one. Everything runs locally in your browser.

A container is opened where it sits and read a range at a time, so a retail .nsp or cartridge image never has to fit in memory. It needs prod.keys, which the Files panel takes.

Keyboard: arrows = D-pad · Z/X = A/B · A/S = X/Y · Q/E = L/R · Enter = + · Shift = −. A connected gamepad is used automatically.
